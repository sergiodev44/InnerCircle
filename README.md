# InnerCircle
### ES
InnerCircle es una aplicación web para comprar y vender ropa de segunda mano dentro de tu círculo de confianza. Publica prendas, conecta con amigos y cierra tratos de forma directa, sin intermediarios.

### EN
InnerCircle is a web app for buying and selling secondhand clothing within your trusted circle. List items, connect with friends, and close deals directly — no middlemen.
